The system, as these samples model it

A notional drawing based on public NAVAIR descriptions, not the program's official architecture.

How the set is single-sourced

One pool of DITA topics feeds the manual, the How-To Guides, and training. The CCS-07 source shows each mechanism with comments.

Mechanisms

  • Bookmap — decides what goes in each deliverable, and in what order
  • Keys — release number and paths set once per release
  • Conref — every warning and caution written once and reused
  • Filtering — @platform, @product, @audience build each edition
  • Topic types — concept, task, reference, troubleshooting, glossary

What strict validation enforced

  • A warning in a task step is only allowed before the action
  • Appendices sit in the bookmap, not inside back matter
  • Reference bodies hold sections and tables, not loose notes
  • Title-page metadata follows a fixed order
  • Details in the source README
